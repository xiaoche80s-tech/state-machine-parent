流程说明

正常流程: create → pick → check → pack → ship → complete
拣货失败: pick → handle-exception → complete
复核不通过: check → re-pick → complete
发货失败: ship → return-inbound → complete

测试场景

正常流程: 预设 picked/packed 成功标志，跳过随机失败逻辑，直接走完 create → pick → check → pack → ship → complete

模拟拣货失败: 拣货必定失败（抛出异常），状态机按重试策略重试，最终走 pick → handle-exception → complete

停在发货状态: 使用 execute(ctx, businessId, "ship") 停在 ship 状态（REACHED），后续可点击 resume 继续执行

模拟发货失败: 预设 picked/packed 成功，但不设置 shipped，ship 状态条件 ctx.isShipped() 为 false，走 ship → return-inbound → complete 异常路径
